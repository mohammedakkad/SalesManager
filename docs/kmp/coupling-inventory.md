## Firebase access model (feeds K1.3)

Read and described only; nothing was changed. File:line references are to this checkout.

### (a) Does the seller app use Firebase Auth?

**No, in no form.** Searched `app`, `salesmanager`, `admin` sources, manifests and Gradle files for `FirebaseAuth`, `signInAnonymously`, `signInWithCustomToken`, `signInWith*`, `currentUser`, `getIdToken`, `firebase.auth`:

- The only hits are in **`:admin`**: `admin/.../ui/auth/AuthViewModel.kt:23` (`FirebaseAuth.getInstance()`), `:28` (`currentUser`), `:45` (`signInWithEmailAndPassword`). The admin signs in with email and password.
- `:app` declares `api(libs.firebase.auth)` (`app/build.gradle.kts:51`), so the library is on the seller classpath, but **no seller source calls it**. No anonymous sign-in, no custom token.
- Consequence (inference from the code, **rules not in the repo**): the seller reaches Realtime Database and Firestore **unauthenticated** (`request.auth == null`). Anything it can do is allowed by the server rules to an anonymous client.

### (b) How a seller is tied to a merchant

The tie is the **activation code**, typed by the user; there is no other credential in the code.

- Validation: `FirebaseSyncService.validateCodeDetailed(code)` reads Realtime Database `activation_codes/{code}` and maps `status` to Active, Disabled, Expired or NotFound (`app/.../data/remote/FirebaseSyncService.kt:83-99`, path constant `:916`).
- Storage: the code is saved in DataStore as `MERCHANT_CODE` (`ActivationRepositoryImpl.kt:65-68`) and exposed to merchant-scoped code through `MerchantContext.currentCode()` (`domain/repository/MerchantContext.kt`, implemented in `ActivationMerchantContext.kt`). After activation, imported records get `merchantId = code` (`ActivationRepositoryImpl.kt:178`).
- **The code is in the path of every remote call** (merchant isolation is by path, not by identity):
  - Realtime Database: `activation_codes/{code}` (status, subscription fields: `MerchantStatusRepositoryImpl.kt:18,49-54`); `merchants/{code}/{customers, payment_methods, transactions, invoice_items, return_invoices, cash_boxes, cash_box_movements}` (`FirebaseSyncService.kt:135-137,190-366,419-495`); `merchants/{code}/sessions/{sessionId}` (`FirebaseSyncService.kt:135-138`, `SessionsViewModel.kt:48`); `subscription_requests/{code}/{key}` (`FirebaseSubscriptionRepositoryImpl.kt:25-53`, `FirebaseSyncService.kt:108`); outbox writes `merchants/{merchantId}/_sale_events|_sale_heads` (`FirebaseOutboxTransport.kt:66-89`).
  - Firestore: `merchants/{merchantId}/products/{id}/units`, `stock_movements`, `invoice_items` (`ProductFirestoreService.kt:13-63`); `chat/{merchantId}/messages` and `notifications/{merchantId}` (`ChatService.kt:20-22,75`); outbox receipts/heads under `merchants/{merchantId}/_sale_events|_sale_heads` in a transaction (`FirebaseOutboxTransport.kt:36-39`).
  - **A query across all merchants:** FCM token registration runs `collection("merchants").whereEqualTo("activationCode", code)` and updates `fcmToken` on the first match (`ChatNotificationService.kt:55-59,115-119`). That needs list access to the merchants collection for an anonymous client.
- The admin app writes merchants as Firestore documents keyed by `merchant.id` with an `activationCode` field, and mirrors status into `activation_codes/{code}` (`MerchantAdminService.kt:19,92,105-112`). **Whether the Firestore document id equals the activation code (which the seller paths assume) is not verifiable from the repository**: to be confirmed with the owner's data and rules.

### (c) Firebase security rules in the repository

**Rules not in repo — owner must export them before K1.3.** No `database.rules.json`, `firestore.rules`, `firebase.json`, `.firebaserc` or indexes file exists (`git ls-files`, and a search of the tree). Nothing in the repository enforces merchant isolation on the server; the client-side isolation is the `MerchantContext` plus the Phase 6 isolation tests.
The repository already says so: `docs/qa/stage11-server-contract.md:48`: "Repository inspection found no Firebase rules/functions deployment source ... Required input is rule text from each database's Rules tab plus the actual identity/membership or Custom Claims contract. Do not infer authorization from locally saved activation codes or invent/deploy permissive rules." And `:44`: client-side guards "cannot replace deployed server rules".
Needed from the owner before the K1.3 decision: the Rules tab text of Realtime Database and of Firestore, and a statement of how `merchants/{id}` documents are keyed.

### Implications for the K1.3 options

- An unauthenticated client authorised only by knowing a path is easy to reproduce with REST (option b) or a KMP SDK (option a): neither needs an auth flow. The real constraints are the rules and the `whereEqualTo` collection query.
- Realtime listeners and offline caching on desktop remain unverified (see `dependency-matrix.md`).

## Surprises

1. **The PDF layout engine depends on `android.text`.** 19 files under `util/pdf` import `android.text.Layout` / `StaticLayout` or `android.graphics.Canvas/Bitmap/Path/Rect`. Text measurement and line breaking go through `StaticLayout`, not only the final `PdfDocument` sink. "Move the layout engine to commonMain behind `PdfPageSink`" (K6.2) is therefore not a move: the text-measurement and canvas parts need their own abstraction, and **Arabic shaping and bidi currently come from Android's text engine**. This enlarges the K6.1 spike.
2. **`:app` is not Android-free.** 14 of its 116 files import `android.*` (`Context`, `Log`, `ConnectivityManager`, `Bitmap`, notifications, `SharedPreferences`), including data-layer files such as `ActivationRepositoryImpl`, `AppDatabase`, `DataStoreProvider`, `DeviceFingerprintProvider`.
3. **WorkManager sits inside a "remote" class.** `FirebaseSyncService.kt` imports `androidx.work`; the other WorkManager files are workers (`StatusCheckWorker`, `SaleOutboxWork`, `LowStockCheckWorker`, `UnpaidDebtWorker`, `BackgroundUpdateWorker`, `AdminAlertsWorker`).
4. **Domain interface with a Firebase parameter** (`MerchantAdminRepository`), see above.
5. The seller never authenticates and the seller's FCM registration queries the whole `merchants` collection (see (a) and (b)).
6. `okhttp3` is imported by one file (`CloudinaryUploader.kt`) and `org.json` by the same file: an image upload client that is Android-flavoured.
7. 160 of 277 files are small (S). Of the 44 **L** files, 36 are presentation (screens and view models); none is in the PDF engine (all its files are S or M).

#!/usr/bin/env python3
"""K0.3 Android-coupling inventory. Run from the repository root:
    python3 -I /path/to/coupling.py --out docs/kmp/coupling-inventory.md   (see the doc for the exact command)
Reads every *.kt under {app,salesmanager,admin}/src/main. No network, no build."""
import os, re, sys, json, collections, argparse

MODULES = ["app", "salesmanager", "admin"]
IMP = re.compile(r"^import\s+([\w.*]+)(?:\s+as\s+\w+)?\s*$", re.M)


def kt_files(root):
    for m in MODULES:
        base = os.path.join(root, m, "src", "main")
        for d, _, fs in os.walk(base):
            for f in sorted(fs):
                if f.endswith(".kt"):
                    yield m, os.path.join(d, f)


def layer_and_target(m, rel):
    """rel = path below src/main/java/ (package path). Returns (layer, target module, hint)."""
    p = rel
    if m == "app":
        if "/domain/model/" in p: return "domain", ":shared:core-model", "model"
        if "/domain/repository/" in p or "/domain/usecase/" in p: return "domain", ":shared:core-domain", ""
        if "/data/local/entity/" in p or "/data/local/dao/" in p or "/data/local/db/" in p or p.endswith("/data/local/") or "/data/migration/" in p: return "data", ":shared:core-data", "room"
        if "/data/local/" in p: return "data", ":shared:core-data", "datastore"
        if "/data/repository/" in p or "/data/manager/" in p: return "data", ":shared:core-data", ""
        if "/data/remote/" in p or "/sync/" in p: return "remote", ":shared:core-remote", ""
        if "/worker/" in p: return "platform", ":salesmanager (+ desktop scheduler)", "worker"
        if "/util/format/" in p: return "domain", ":shared:core-domain", "format"
        if "/util/" in p: return "platform", ":shared:core-domain / jvmShared", "util"
        if "/ui/" in p: return "presentation", ":shared:seller-ui", ""
        if "/device/" in p: return "platform", ":salesmanager (interface in core-domain)", "device"
        return "platform", "?", ""
    if m == "salesmanager":
        if "/ui/" in p: return "presentation", ":shared:seller-ui", ""
        if "/util/pdf/" in p: return "platform", ":shared:core-pdf", "pdf"
        if "/util/export/" in p: return "platform", ":shared:core-data / jvmShared", "export"
        if "/di/" in p: return "DI", ":salesmanager (Android DI) + shared Koin modules", ""
        if "/sales/outbox/" in p or p.endswith("/sales/") or "/sales/" in p: return "data", ":shared:core-data", "outbox"
        if "/worker/" in p: return "platform", ":salesmanager (+ desktop scheduler)", "worker"
        if "/update/" in p: return "platform", ":salesmanager (interface+DI)", "update"
        if "/service/" in p: return "platform", ":salesmanager", "service"
        if "/util/" in p: return "platform", ":shared:core-domain / jvmShared", "util"
        return "platform", ":salesmanager", "app"
    if m == "admin":
        if "/ui/" in p: return "presentation", ":admin (K10)", ""
        if "/di/" in p: return "DI", ":admin (K10)", ""
        return "platform", ":admin (K10)", "app"
    return "?", "?", ""


def analyse(root):
    rows = []
    for m, path in kt_files(root):
        src = open(path, encoding="utf-8").read()
        rel = path.split("/src/main/java/")[-1] if "/src/main/java/" in path else path.split("/src/main/")[-1]
        rel = "/" + os.path.dirname(rel) + "/"
        layer, target, hint = layer_and_target(m, rel)
        imports = IMP.findall(src)
        loc = sum(1 for l in src.splitlines() if l.strip() and not l.strip().startswith(("//", "*", "/*")))
        c = collections.OrderedDict()
        android = sorted({".".join(i.split(".")[:3]) for i in imports if i.startswith("android.") and not i.startswith("androidx.")})
        c["android.*"] = android
        c["android.graphics.pdf"] = [i for i in imports if i.startswith("android.graphics.pdf")]
        c["pdf_token"] = ("PdfDocument" in src)  # substring on purpose: also matches wrapper names such as PdfDocumentBuilder
        c["android_print"] = [i for i in imports if i.startswith("android.print")]
        c["android_text_canvas"] = [i for i in imports if i.startswith(("android.text", "android.graphics"))]
        c["firebase"] = sorted({".".join(i.split(".")[:4]) for i in imports if i.startswith("com.google.firebase")})
        c["gson"] = [i for i in imports if i.startswith("com.google.gson")]
        c["workmanager"] = [i for i in imports if i.startswith("androidx.work")]
        c["camerax"] = [i for i in imports if i.startswith("androidx.camera")]
        c["mlkit"] = [i for i in imports if i.startswith("com.google.mlkit")]
        c["crypto"] = [i for i in imports if i.startswith(("javax.crypto", "org.bouncycastle", "java.security"))]
        c["javax.crypto|bouncycastle"] = [i for i in imports if i.startswith(("javax.crypto", "org.bouncycastle"))]
        c["context"] = ("android.content.Context" in imports)
        c["resources"] = bool(re.search(r"^import\s+[\w.]+\.R\s*$", src, re.M) or re.search(r"\bR\.(string|drawable|color|raw|font|plurals|mipmap|id|xml)\b", src) or re.search(r"\b(stringResource|painterResource|pluralStringResource|colorResource)\(", src))
        c["room"] = [i for i in imports if i.startswith("androidx.room")]
        c["datastore"] = [i for i in imports if i.startswith("androidx.datastore")]
        c["androidx_other"] = sorted({".".join(i.split(".")[:2]) for i in imports if i.startswith("androidx.") and not i.startswith(("androidx.compose", "androidx.room", "androidx.datastore", "androidx.work", "androidx.camera"))})
        c["compose"] = any(i.startswith("androidx.compose") for i in imports)
        c["koin"] = any(i.startswith("org.koin") for i in imports)
        c["okhttp"] = any(i.startswith("okhttp3") for i in imports)
        c["fq_android"] = bool(re.search(r"(?<![\w.\"])android\.(content|app|os|net|util|graphics|view|widget|provider|database|print|text|webkit|media|location|telephony|Manifest)\.[A-Za-z]", re.sub(r"^import .*$", "", src, flags=re.M)))
        c["fq_firebase"] = bool(re.search(r"(?<![\w.\"])com\.google\.firebase\.[A-Za-z]", re.sub(r"^import .*$", "", src, flags=re.M)))
        c["firebase_types"] = sorted(set(re.findall(r"\b(Timestamp|DataSnapshot|DatabaseReference|FirebaseFirestore|FirebaseDatabase|FirebaseAuth|FieldValue|ServerValue|DocumentSnapshot|QuerySnapshot|FirebaseMessaging|RemoteMessage)\b", src)))
        rows.append(dict(module=m, path=os.path.relpath(path, root), pkgpath=rel, layer=layer, target=target, hint=hint, loc=loc, c=c, imports=len(imports)))
    return rows


def size_class(loc):
    return "S" if loc <= 80 else ("M" if loc <= 250 else "L")


def strategy(r):
    c = r["c"]; layer = r["layer"]; hint = r["hint"]
    fb = bool(c["firebase"]) ; and_ = bool(c["android.*"]) or c["fq_android"]
    if layer == "domain" and hint == "model" and (fb or c["firebase_types"]):
        return "K2.3: replace Firebase types with epoch millis/kotlinx-datetime in the domain; convert in the mapping layer"
    if c["camerax"] or c["mlkit"]:
        return "interface + DI; stays in app module (desktop: keyboard-wedge scanner)"
    if c["workmanager"]:
        return "interface + DI; stays in app module (desktop: coroutine scheduler, K4.5)"
    if hint == "pdf":
        if c["android.graphics.pdf"]:
            return "expect/actual: Android PdfPageSink (android.graphics.pdf.PdfDocument) stays in androidMain"
        if c["android_print"]:
            return "interface + DI; Android print manager stays in app module (desktop: system print dialog)"
        if c["android_text_canvas"] or and_:
            return "expect/actual: text measurement/canvas (android.text, android.graphics) behind the sink API; layout moves to core-pdf"
        return "move to core-pdf commonMain as-is (K6.2)"
    if fb and layer in ("remote", "data", "platform", "presentation", "DI"):
        return "interface + DI; Android Firebase impl stays (androidMain); desktop per K1.3"
    if c["javax.crypto|bouncycastle"] and not and_:
        return "jvmShared (javax.crypto + BouncyCastle)"
    if c["javax.crypto|bouncycastle"] and and_:
        return "jvmShared for the crypto part; split Android part (Context/Uri) behind an interface"
    if c["gson"] and not and_:
        return "jvmShared (Gson) or kotlinx.serialization in commonMain"
    if layer == "DI":
        return "stays in app module (Android DI); shared Koin modules move"
    if layer == "presentation" and (and_ or c["context"] or c["resources"] or c["androidx_other"]):
        return "move with the screen; replace android.*/R/Context via Compose resources or interface + DI"
    if layer == "presentation":
        return "move as-is to seller-ui (Compose Multiplatform)"
    if hint == "room" or c["room"]:
        return "move to core-data (Room KMP); keep schema"
    if hint == "datastore" or c["datastore"]:
        return "move to core-data (DataStore KMP); keep file name"
    if and_ and layer in ("platform", "data", "remote", "domain"):
        return "interface + DI (or expect/actual) around the android.* use"
    if c["okhttp"]:
        return "jvmShared (OkHttp)"
    return "move as-is"


def main():
    ap = argparse.ArgumentParser(); ap.add_argument("--root", default="."); ap.add_argument("--json"); a = ap.parse_args()
    rows = analyse(a.root)
    for r in rows:
        r["strategy"] = strategy(r); r["size"] = size_class(r["loc"])
    if a.json:
        json.dump(rows, open(a.json, "w"), indent=1)
    return rows


if __name__ == "__main__":
    main()
